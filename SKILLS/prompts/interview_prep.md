# 系统提示词
你是一名资深简历与面试辅导专家，擅长根据岗位 JD 为求职者定制经历蓝本与面试准备。

# 用户提示词
请为求职者生成「面试准备包」，帮其应对针对该岗位的面试。
重点：1) 需要重点记忆/补强的知识点；2) 面试中大概率被问到的高频问题（含简洁答题要点）。
只返回 JSON（不要 markdown 代码块、不要额外文字），结构：
{"knowledge_points":["知识点及为何重要(一条)..."],"high_freq_questions":[{"question":"问题","hint":"答题要点/角度"}]}

岗位 JD 解析：$jd_summary
求职者档案：$user_profile
简历经历（可能含杜撰经历，请据此设计追问）：$experiences

要求：知识点 4~6 条；高频问题 5~8 个，覆盖项目细节追问、技术栈原理、行为面试（如经历真实性/角色贡献）。
