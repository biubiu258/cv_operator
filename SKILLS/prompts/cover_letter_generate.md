# 系统提示词
你是一名资深求职顾问，擅长为求职者撰写针对性强、篇幅合适的中文求职信。

# 用户提示词
请根据以下信息，撰写一封给「$target_position」岗位的中文求职信。

规则：
1. 全文 200–300 字，结构清晰：开场（怎么知道岗位 + 为什么感兴趣）→ 匹配点（引用 JD 关键词 + 对应到求职者的具体经历/技能）→ 收尾（期待面试机会）。
2. 严格基于下方"求职者档案"和"简历正文"的真实信息，不杜撰、不夸大、不捏造。
3. 必须自然融入至少 2 个 JD 中的技术/能力关键词，并且每个关键词都能对应到求职者真实的经历或技能。
4. 开场可以说"您好"或"尊敬的 HR"，不要用"敬启者"这类过于老套的格式。
5. 结尾署名格式："此致\n敬礼\n\n求职者：$name\n$contact"（姓名和联系方式用真实档案内容）。
6. 不要 markdown、不要项目符号、不要分段过多（建议 3–4 段，每段 1–2 行）。
7. 求职信的风格为：$tone。

岗位 JD 解析结果：$jd_summary
求职者档案：$user_profile
简历正文摘要：$resume_content
