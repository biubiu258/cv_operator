# 用户提示词

$extra_block
真实性要求：公司名与岗位名应真实存在（可取自 JD），职责与 JD 呼应、技术栈匹配；求职者并未真实入职，但内容需自洽、可量化、经得起面试追问。
紧扣真实技能与经验：必须严格基于下方「求职者技能与经验」中已具备的技能及其熟练程度来设计，不得杜撰其不具备的高阶技能；「了解 / 熟悉」级技能不可写成「主导 / 自研 / 独立完成」高阶工作；熟练度与经历深度匹配。

【时间窗口纪律 —— 最高优先级，必须严格遵守】
系统已依据求职者的教育时间线与真实经历，预先规划好每段经历的起止时间，见下方「时间窗口规划」。
1. 每类经历必须严格使用规划中分配的 start_date / end_date，一个字都不得改动；按规划中窗口的先后顺序生成对应经历。
2. 某类型的窗口列表为空时，不得生成该类型经历；返回经历总数不得超过窗口总数。
3. 结束时间为「至今」的窗口，必须保留「至今」；这些窗口已保证就业链连续、无空档（gap）、无重叠、不与在校学习冲突，你无需也不得自行调整时间。
4. 仍需保证：全职（work）经历不早于毕业日期，任何经历不晚于当前日期，同类型经历按时间从新到旧排列。
