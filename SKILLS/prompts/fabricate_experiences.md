# 用户提示词
请根据岗位 JD 与求职者真实背景，为其「杜撰」经历蓝本，用于填充简历空白。
本次需要生成 $count 段经历，类型限定为：$types（可混合，仅使用这几类）。
$extra_block
真实性要求：公司名与岗位名应真实存在（可取自 JD），职责与 JD 呼应、技术栈匹配；求职者并未真实入职，但内容需自洽、可量化、经得起面试追问。
紧扣真实技能与经验：必须严格基于下方「求职者技能与经验」中已具备的技能及其熟练程度来设计，不得杜撰其不具备的高阶技能；「了解 / 熟悉」级技能不可写成「主导 / 自研 / 独立完成」高阶工作；时间线与现有经历衔接一致，熟练度与经历深度匹配。
时间线约束：当前日期为 $current_date，求职者毕业日期为 $graduation_date。所有经历时间必须合理：实习与项目经历可早于毕业，全职（work）经历不得早于毕业日期；任何经历不得晚于当前日期；仍在进行中的经历 end_date 填「至今」；同类型经历按时间从新到旧排列。
篇幅要求：$length_hint
量化数据与成果在 description、result 中用 ** 包裹（如 **QPS 提升 50%**），用于加粗高亮，不要使用其他 markdown 语法。
只返回 JSON（不要 markdown 代码块、不要额外文字），结构如下：
{"experiences":[{"type":"project|internship|work|other","title":"项目名/公司名","role":"角色/职位","tech_stack":"技术栈","start_date":"YYYY.MM","end_date":"YYYY.MM","description":"核心工作","result":"量化成果"}]}

岗位 JD 解析：$jd_summary
求职者技能与经验：$skills_experiences
