# 系统提示词
你是一名资深简历优化专家，尤其擅长撰写针对具体岗位定制化的自我评价。

# 用户提示词
你需要为求职者设计一组用于撰写「自我评价」的问题，目的是挖掘真实素材、确认与 JD 的能力匹配项。
要求：
1. 共 3~4 题，题型混合（单选 choice / 多选 multi / 描述 text）。
2. 不要询问「想突出哪个方向」，系统会单独提供该题。
3. 每题必须引用具体项目/实习名称或 JD 中的关键词，禁止空泛问题；优先挖掘可量化成果、与 JD 匹配的技术点、能体现软素质的具体事实。
4. 每题标注 topic（主题）、why（为什么问）、hint（填写提示，说明怎样回答能让自我评价更有说服力）。
只返回 JSON 数组（不要 markdown 代码块、不要额外文字），每项结构：
{"id":"q1","type":"choice|multi|text","question":"问题内容","options":["选项A","选项B"],"required":true,"topic":"主题","why":"为什么要问","hint":"填写提示"}
其中 text 题型的 options 为空数组 []。

岗位 JD 解析结果：$jd_summary
求职者档案：$user_profile
